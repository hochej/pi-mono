# pi

Tools for building AI agents and managing LLM deployments.

**Looking for the coding agent?** Jump to [Coding Agent](coding-agent/overview.md).

## Packages

| Package | Description |
|---------|-------------|
| [**pi-coding-agent**](coding-agent/overview.md) | Interactive coding agent CLI |
| [**pi-ai**](libraries/ai.md) | Unified multi-provider LLM API |
| [**pi-agent-core**](libraries/agent.md) | Agent runtime with tool calling and state management |
| [**pi-tui**](libraries/tui.md) | Terminal UI library with differential rendering |
| [**pi-web-ui**](libraries/web-ui.md) | Web components for AI chat interfaces |
| [**pi-mom**](mom/overview.md) | Slack bot powered by the pi coding agent |
| [**pi-pods**](pods/overview.md) | CLI for managing vLLM deployments on GPU pods |

## Quick Start

```bash
npm install -g @mariozechner/pi-coding-agent
pi
```
